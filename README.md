# Программирование: от простого к сложному

Сборник проектов и заданий для изучения программирования (C++).


## **Проекты**

### *Уровень 1: Консольные приложения*

1. **Калькулятор с историей операций.**
   - **Этап 1:** Линейная структура для одной операции.
   - **Этап 2:** Ветвление для выбора операции (+, -, *, /).
   - **Этап 3:** Цикл для непрерывной работы до команды "выход".
   - **Этап 4:** Добавить функции для каждой операции.
   - **Этап 5:** Сохранение истории вычислений в файл (файлы последовательного доступа).

2. **Игра "Угадай число".**
   - **Этап 1:** Компьютер загадывает, пользователь угадывает с подсказками "больше/меньше".
   - **Этап 2:** Добавить подсчёт попыток и рейтинг игроков.
   - **Этап 3:** Сохранение таблицы рекордов (имя, количество попыток) в файл.

3. **Система управления библиотекой (мини-версия).**
   - Работа со структурой `Book` (автор, название, год, наличие).
   - Массив/вектор структур для хранения каталога.
   - Функции: добавление, поиск по автору/названию, вывод всего каталога, отметка о выдаче.
   - Сохранение и загрузка каталога из типизированного файла.

4. **Анализатор текстового файла.**
   - Чтение файла. Подсчёт: количество строк, слов, символов.
   - Поиск частоты использования заданного слова.
   - Вывод статистики (самое частое/длинное слово).

5. **Программа для работы с многочленами.**
   - Структура для хранения коэффициентов.
   - Функции: сложение, вычитание, умножение многочленов.
   - Рекурсивное вычисление значения по схеме Горнера.

---

### *Уровень 2: Углубление, алгоритмы и структуры данных*

1. **Архиватор (простейший по алгоритму RLE).**
   - Реализация алгоритма Run-Length Encoding.
   - Создание модуля для работы с алгоритмом (отдельные `.h` и `.cpp` файлы).
   - Подсчёт степени сжатия.

2. **Игра "Сапёр" (консольная версия).**
   - Двумерный массив для поля.
   - Алгоритмы расстановки мин и подсчёта чисел.
   - Рекурсивное открытие пустых областей.
   - Цикл игры с обработкой ввода координат.

3. **To-Do List (Список дел) с динамическими структурами.**
   - Реализация на основе односвязного списка (структура `Task` + указатель `next`).
   - Функции: добавление в начало/конец, удаление, отметка о выполнении, просмотр всех.
   - Усложнение: Двусвязный список, стек для отмены действий.

4. **Калькулятор для выражений в постфиксной записи (Обратная польская нотация).**
   - Реализация стека на основе массива или односвязного списка.
   - Алгоритм вычисления выражения вида `5 3 +` -> `8`.
   - Усложнение: Алгоритм перевода из инфиксной (`(5+3)*2`) в постфиксную запись.

---

### *Уровень 3: Объектно-ориентированное программирование и GUI*

1. **Графический калькулятор.**
   - Создание формы с кнопками и полем ввода.
   - Обработка событий нажатия кнопок.
   - Логика вычислений, инкапсулированная в отдельном классе `CalculatorEngine`.
   - Использование стандартных диалогов для вывода ошибок.

2. **Анкета или тестирующая система.**
   - Несколько форм: форма ввода данных, форма с вопросами (использовать `RadioButton`, `CheckBox`), форма с результатом.
   - Класс `Test`, содержащий список вопросов и ответов.
   - Навигация между формами.
   - Усложнение: Таймер на прохождение теста.

3. **Игра "Пятнашки" (15 Puzzle).**
   - Класс `GameBoard`, отвечающий за логику поля и перемещения костяшек.
   - Создание интерфейса с кнопками или рисование поля на канве.
   - Обработка кликов для перемещения.
   - Проверка на завершение игры. Меню ("Новая игра", "Выход").

4. **Клиент для записной книжки (сетевая версия - как долгосрочный проект).**
   - Фронтенд (GUI): Форма для просмотра, добавления, редактирования контактов (структура `Contact`).
   - Бэкенд (логика + файлы): Отдельный класс `NotebookService` для управления данными, работа с файлами.
   - ООП: Чёткое разделение на классы Model (`Contact`, `NotebookService`), View (форма), Controller (обработчики событий).
   - Тестирование: Написание unit-тестов (например, с помощью библиотеки Google Test) для методов `NotebookService`.

5. **Симулятор банкомата.**
   - Многомодульная структура: Модуль для работы с аккаунтами (`Account`), модуль для транзакций, модуль интерфейса.
   - GUI: Форма ввода PIN, главное меню, операции (баланс, снятие, перевод).
   - Работа с данными: Хранение данных о картах, счетах и транзакциях в бинарных файлах прямого доступа (для быстрого поиска по номеру карты).
   - Безопасность: Шифрование PIN-кодов (простейшее, для демонстрации).
   - Логирование: Запись всех операций в лог-файл.
   - Тестирование: Юнит-тесты для критических модулей.

## **Практические задания**

### *Основы языка*

1. **Преобразование типов:** написать программу, демонстрирующую:
   - Неявное преобразование при операциях с разными типами
   - Явное преобразование с помощью `static_cast`
   - Потерю данных при преобразовании `float` → `int`

2. **Ввод/вывод:** написать программу, которая запрашивает у пользователя имя и год рождения, затем вычисляет и выводит возраст.

3. **Do-while:** написать программу, которая запрашивает пароль, пока не будет введен правильный.

4. **Break/continue:** в цикле от 1 до 100 пропустить вывод чисел, кратных 7, и остановиться при достижении 50.

5. **Одномерный массив:** заполнить массив случайными числами и найти:
   - Максимальный и минимальный элементы
   - Среднее арифметическое
   - Сумму положительных элементов

6. **Поиск:** реализовать линейный поиск элемента в массиве.

7. **Обработка:** удалить из массива все нулевые элементы (со сдвигом).

8. **Двумерный массив:** заполнить матрицу и:
   - Вывести элементы главной и побочной диагоналей
   - Найти сумму элементов каждого столбца
   - Транспонировать матрицу

9. **Бинарный поиск:** реализовать бинарный поиск в отсортированном массиве.

10. **Множества:** реализовать операции над множествами (объединение, пересечение, разность) для массива чисел.

11. **Структура:** создать структуру `Student` с полями: имя, фамилия, оценки по 3 предметам.

12. **Массив структур:** создать массив из 10 студентов и:
    - Найти студента с максимальным средним баллом
    - Вывести список студентов, имеющих хотя бы одну двойку
    - Отсортировать по фамилии

13. **Текстовые файлы:** написать программу, которая:
    - Считывает текст из файла и подсчитывает количество слов
    - Копирует содержимое одного файла в другой
    - Удаляет все пустые строки из файла

14. **Форматированный вывод:** вывести таблицу значений функции y = x² в файл с выравниванием колонок.

15. **Бинарные файлы:** сохранить массив целых чисел в бинарный файл и считать его.

16. **Простые функции:** написать функции для:
    - Проверки числа на простоту
    - Вычисления НОД двух чисел (алгоритм Евклида)
    - Перевода градусов Цельсия в Фаренгейты

17. **Передача параметров:** продемонстрировать разницу между передачей по значению, по ссылке и по указателю на примере функции обмена значений.

18. **Перегрузка функций:** создать несколько функций с одним именем для вычисления площади:
    - Круга (по радиусу)
    - Прямоугольника (по двум сторонам)
    - Треугольника (по основанию и высоте)

19. **Область видимости:** создать программу с глобальными, локальными и статическими переменными, продемонстрировать их время жизни.

20. **Параметры по умолчанию:** создать функцию вывода строки с параметрами: текст, количество повторений, символ разделитель (иметь значения по умолчанию).

21. **Ханойские башни:** реализовать рекурсивное решение.

22. **Бинарный поиск:** реализовать рекурсивную версию бинарного поиска.

23. **Обход дерева:** дана рекурсивная структура (например, каталог файлов), реализовать подсчет элементов.

### *Указатели и динамическая память*

24. **Утечка памяти:** создать программу, которая демонстрационно вызывает утечку памяти.

25. **Динамические массивы:** создать динамический массив, заполнить, отсортировать, освободить память.

26. **Указатели и массивы:** показать эквивалентность записи `*(arr + i)` и `arr[i]`.

27. **Динамические структуры:** создать динамическую переменную типа структуры `Student`.

    - Удаление по значению
    - Поиск элемента
    - Вывод всего списка

30. **Обратная польская запись:** реализовать калькулятор выражений в постфиксной записи с использованием стека.

31. **Проверка скобок:** используя стек, проверить правильность расстановки скобок в выражении.

### *Комплексные задачи*

    - Открывать/сохранять файлы
    - Изменять шрифт
    - Поиск текста

    - Добавлением/редактированием записей
    - Поиском
    - Формированием отчетов
    - Сохранением в файл

45. **Сетевой чат:** клиент-серверное приложение для обмена сообщениями (используя сокеты).

46. **Шифрование:** реализовать программу для шифрования/дешифрования файлов простым алгоритмом (XOR или шифр Цезаря).

47. **Архиватор:** реализовать простой архиватор с использованием алгоритма Хаффмана.

48. **Интерпретатор:** написать простой интерпретатор арифметических выражений.

49. **Мини СУБД:** реализовать систему управления данными с поддержкой простых SQL-подобных запросов.
